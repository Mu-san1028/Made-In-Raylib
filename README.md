# Made-In-Raylib
　『Made-In-Raylib』は、C言語とraylibで作った、10種類のミニゲームに次々と挑戦するPCゲームです。タイピング、的当て、神経衰弱、リズムゲームなどを制限時間内にクリアし、スコアを伸ばします。
『メイド イン ワリオ』のように短いゲームが次々と切り替わる遊びを参考に、キーボードとマウスを使ったPC向けの操作を取り入れました。

## ここが面白いぞ！
### 様々なミニゲームで、頭と手を切り替える！

タイピングでは表示された単語を入力し、的当てでは動く的を狙って弾を撃ちます。巻物を広げるゲームでは、マウスを横にドラッグして制限時間内に最後まで開きます。同じ操作を繰り返すうちに上達する遊びとは違い、画面が切り替わるたびに、何をすればクリアできるかを見てすぐに動くところが面白さです。

## 工夫したところ

### 10種類のミニゲームを、共通のゲームループで進める

ミニゲームごとにルールや操作は異なりますが、開始時に初期化し、毎フレーム入力を処理して描画する流れは共通しています。そこで、各ミニゲームを `初期化・更新・描画` の3つの関数に分け、それぞれの関数ポインタをミニゲーム一覧に登録しました。

メインループは、現在のミニゲームに登録された関数を呼び出します。制限時間やクリア・失敗の状態は共通の構造体に持たせ、スコアや残機はメインループで管理しています。この構成にしたことで、ミニゲームを追加するときは、そのゲーム固有のルールを実装して一覧に登録すれば、既存のゲーム進行に組み込めます。

[共通データと関数ポインタの定義](game.c#L108-L131) · [ミニゲームの登録一覧](game.c#L1774-L1790)

### ウィンドウを拡大しても、見た目とクリック位置を揃える

コイン集めや神経衰弱では、画面上に描いたものとマウスの当たり判定が一致している必要があります。そこで、ゲーム画面はまず800×450の仮想解像度で描画し、ウィンドウの大きさに合わせて縦横比を保ったまま拡大・縮小しています。

入力側では、マウス座標から画面の余白分を引き、拡大率で割って仮想座標に戻します。これにより、ウィンドウのサイズが変わっても、コインやカードを見た位置でクリックできます。

[マウス座標の変換](game.c#L47-L65) · [画面サイズに合わせた描画](game.c#L1967)

### 短いゲームの連続に、音でテンポをつける

入力や成功・失敗に合わせて効果音を使い分けました。さらに、スコアが一定の段階に達すると難易度とともにBGMの再生速度も上がります。遊びが進むほど操作が忙しくなる変化を、音でも感じられるようにしました。

[スコアに応じた難易度とBGMの変更](game.c#L1923-L1945)
